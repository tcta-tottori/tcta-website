本ファイルは、サイトに掲載する**実テキスト（コピー）と構成**を定義した原稿仕様書です。`design.md` がビジュアルを、本ファイルが言葉を担当します。

- 対象サイト: 鳥取市テニス協会 公式ホームページ（リニューアル）
- 情報ソース: 現行サイト https://www.tottori-tenis.net/ ／ 令和8年度大会日程PDF ／ 水曜テニス教室ページ ／ 協会登録ページ

## 0. このファイルの使い方

### 0.1 記法

| 記法 | 意味 |
| --- | --- |
| `【要確認】` | 協会内で事実確認が必要な箇所。公開前に必ず確定させる |
| `【A案】/【B案】` | コピーの選択肢。ディレクター判断で1つを採用 |
| `{ }` | CMSから流し込む可変値 |
| `→` | 遷移先 |

### 0.2 執筆の基本方針

現行サイトの情報は正確で量も十分ですが、**PDFと画像の中に閉じ込められている**のが最大の課題です。「令和8年度大会日程.pdf」を開かないと大会名すら分からず、協会規約は画像のためスマートフォンで拡大しないと読めません。

本リニューアルの原稿は、この方針で書きます。

1. **PDFの中身をHTMLテキストにする。** 大会名・日程・締切・会場・種目は本文として書く。PDFは「原本」として残し、あくまで補助にする。
2. **「登録が必要かどうか」を先に答える。** 現行の日程表では、市登録・県登録・登録不要の区分がPDF欄外の丸数字注記になっている。これはこのサイトで**最も知りたい情報**なので、大会一覧の先頭に置く。
3. **専門用語を1回だけ言い換える。** 「市登録」「県登録」「クラブ対抗戦」は、初出時に必ず1文で説明を添える。
4. **「こちら」だけのリンクを書かない。** 行き先が分かる文言にする。
5. **敬体（です・ます）で統一。** 硬い告示文ではなく、隣のコートから声をかけるような距離感で。ただし日程・締切・金額は正確第一で、装飾しない。

### 0.3 表記ルール

| 項目 | ルール | 例 |
| --- | --- | --- |
| 年度表記 | 和暦を主、西暦を従（併記） | 令和8年度（2026年度） |
| 日付（本文） | 年月日＋曜日 | 2026年8月30日（日） |
| 日付（カード・一覧） | `YYYY.MM.DD`。期間は `- MM.DD` | 2026.11.07／2026.07.05 - 07.06 |
| 時刻 | 24時間表記 | 18:00〜21:00 |
| 金額 | 三桁区切り＋「円」 | 1,500円 |
| 大会名 | 正式名称。回数を含む | 第49回ダンロップテニストーナメント |
| 会場略称 | 初出は正式名称、以降は略称可 | 鳥取市千代テニス場（以下「千代」） |
| 数字 | 半角 | 4面、19大会 |
| 自称 | 「本協会」または「鳥取市テニス協会」 | — |
| 英字ラベル | 大文字 | TOURNAMENT / NEWS / COURT GUIDE |

### 1.3 通知バー（Notice Bar）

**新設を提案します。** 現行サイトのトップ最上部は常に「大会エントリー受付中／◯/◯締切」で、これが実質的なトップコンテンツになっています。ヘッダーの上に細い帯を置き、CMSからON/OFFできるようにします。

**受付案内（通常時）**
```
【受付中】{大会名}｜エントリー締切 {日付}（{曜日}）　→ 大会要項を見る
```

表示例:
> 【受付中】第30回エネトピア杯ミックスダブルス｜エントリー締切 10月2日（金）　→ 大会要項を見る

**中止告知（緊急時）**
```
⚠ 【中止】{大会名}（{日付}）は荒天のため中止となりました。　→ 詳細を見る
```

- 締切日を過ぎたら自動で非表示（CMSで締切日を持つ）
- **中止告知は必ずこの通知バーとセットで出します。** カードのバッジだけでは見落とされます（`design.md` §2.3 参照）

```
　カレンダー右下の「＋Googleカレンダー」ボタンを押してください。

```
